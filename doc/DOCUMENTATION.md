# Documentation conventions

All repository documentation and future documentation changes must be written in English. This applies to READMEs, hardware instructions, test evidence, release notes, historical document translations and documentation added during development.

Preserve commands, GPIO assignments, file paths, MAC addresses, dates and observed log values exactly. Keep historical results distinct from current behavior and pending hardware checks. Label translations of spoken phrases as translations; changing documentation must not change Russian or German audio assets or firmware behavior.

Use English filenames for new documents and maintain links when renaming documentation. Firmware strings, audio recordings, third-party source notices and original binary reference material are separate from the documentation language policy.
