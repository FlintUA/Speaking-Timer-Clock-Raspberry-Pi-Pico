# Speaking Clock 1.0.0

First stable source release of the C / Pico SDK firmware for Raspberry Pi Pico 2 W.

## Features

- Countdown timer with precise entry, five weekday alarms and a three-minute snooze.
- Russian and German speech, hourly announcements, date and nearest alarm, quiet hours, and five annual birthday dates.
- Music player with normal, shuffle and repeat-one modes, track history, pause/resume and a sleep timer.
- Local DFPlayer and Bluetooth Classic A2DP audio, with independent volume levels adjusted by one encoder and local fallback.
- Bluetooth discovery, pairing, up to four saved speakers and direct reconnect without scanning. Disconnect or starting discovery persists OFF until the next explicit Connect.
- Wi-Fi/NTP with Europe/Berlin daylight-saving rules and RTC operation offline.
- External LCD illumination on GP6 with OFF, ON and AUTO plus day and night levels. About and USB report the firmware version derived from the Git tag.

## Build and update

Use Pico SDK 2.3.1 and the pinned Helix checkout from the [build instructions](https://github.com/FlintUA/Speaking-Timer-Clock-Raspberry-Pi-Pico/blob/v1.0.0/README.md#dependencies-and-build). Use a Git checkout at the exact release tag to embed version 1.0.0.

```powershell
git fetch --tags
git switch --detach v1.0.0
powershell -ExecutionPolicy Bypass -File .\build-clock-bt.ps1 -Mp3
```

Keep `speaking_clock_c.build-id.txt` beside the UF2 for verification by the Windows updater. Flash v11 reads v1-v10 and defaults to illumination OFF for older records. Loading settings leaves the existing Flash record in place until a save is needed. For a network-free fallback with v11 support, build this release with `-NoWifi`. [Wiring](https://github.com/FlintUA/Speaking-Timer-Clock-Raspberry-Pi-Pico/blob/v1.0.0/doc/HARDWARE_PICO2W.md) · [Controls](https://github.com/FlintUA/Speaking-Timer-Clock-Raspberry-Pi-Pico/blob/v1.0.0/doc/CONTROLS_AND_MODES.md) · [Network setup and rollback](https://github.com/FlintUA/Speaking-Timer-Clock-Raspberry-Pi-Pico/blob/v1.0.0/doc/NETWORK_TIME.md)

This release provides source archives and local build instructions. The Pico SDK, BTstack and Helix retain their respective licenses.

## Verification and follow-up

The assembled clock was checked for timer completion and priority, scheduled hourly speech and alarms, Bluetooth reconnect with JBL Link Portable and Google Nest Audio, NTP synchronization, illumination brightness and settings persistence. [Hardware test evidence](https://github.com/FlintUA/Speaking-Timer-Clock-Raspberry-Pi-Pico/blob/v1.0.0/doc/HARDWARE_TEST_EVIDENCE.md)

Overnight operation, Wi-Fi outage recovery and timed AUTO illumination transitions remain follow-up checks. The initial Bluetooth switch can still require a retry. The occasional double sound on Portable and the SSTB 10 C2 compatibility observations remain unresolved. The German timer-completion recording is still missing. The current wiring is documented in the pin map. [Roadmap](https://github.com/FlintUA/Speaking-Timer-Clock-Raspberry-Pi-Pico/blob/v1.0.0/doc/ROADMAP.md)
